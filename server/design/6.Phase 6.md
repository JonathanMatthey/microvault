# Phase 6 — Charging Model & Ledger Improvements (Periodic Storage Billing & Transaction History)

## Purpose

Phase 6 improves the monetization system by implementing:

1. **Periodic Storage Charging**: Currently, storage costs are only _calculated and displayed_. Phase 6 introduces a configurable charging frequency that automatically debits users for stored data at regular intervals (e.g., hourly, every 6 hours, daily).

2. **Transaction History**: Users can now view their complete transaction history (last 100 transactions) in the frontend, providing transparency into charges, refunds, and payments.

The outcome of this phase is:
- Storage charges are **actually deducted** from user accounts at regular intervals
- Administrators configure charging frequency in **minutes** for flexibility
- The system automatically converts `storage_per_gib_month` to the appropriate interval charge
- All transactions (credits, debits, payments) are tracked in Redis with a 100-entry rolling window
- Users can view their transaction history via a new API endpoint
- Accounts are **frozen** when balance goes negative (prevents further usage)
- Transparent billing: users understand exactly what they're being charged for

## Goals

By the end of Phase 6:

- ✅ New config parameter: `charge_frequency_minutes` (e.g., 60 for hourly)
- ✅ Automatic calculation: `interval_storage_cost = (storage_per_gib_month / (30 * 24 * 60)) * frequency_minutes`
- ✅ Background job that runs every `charge_frequency_minutes` and charges all active users
- ✅ Ledger transaction tracking: all debits/credits recorded with timestamps and reasons
- ✅ Redis storage for transaction history (last 100 per user)
- ✅ API endpoint `GET /transactions` returning paginated transaction history
- ✅ Account freeze when balance < 0 (prevent usage)
- ✅ Frontend displays transaction history with charge types and timestamps
- ✅ Tests for charging calculations, rounding, and edge cases
- ✅ Backward compatibility with Phase 5 (no breaking changes to upload/download)

## Non-Goals (Explicitly Out of Scope)

- Refunds or credits reversal (future phase)
- Partial month prorating (assume 30-day months)
- Storage overages or quota enforcement (future phase)
- Scheduled charges beyond periodic storage (e.g., bandwidth throttling)
- Negative balance warnings or grace periods (immediate freeze)
- Payment retry logic (handled by Web Monetization layer)
- Tax calculation or invoicing (future phase)

## Configuration

### New Config Parameters

```yaml
credits:
  scale: 4
  units_per_credit: 10
  ingress_per_gib: 15000             # credits to upload 1 GiB
  egress_per_gib: 30000              # credits to download 1 GiB
  storage_per_gib_month: 10000       # credits to store 1 GiB for a month
  charge_frequency_minutes: 60       # NEW: How often to charge for storage (e.g., 60 = hourly)
```

### Calculation Formula

```
month_minutes = 30 * 24 * 60 = 43,200 minutes

interval_storage_charge_per_gib = (storage_per_gib_month / month_minutes) * charge_frequency_minutes

Example:
- storage_per_gib_month = 10,000 credits
- charge_frequency_minutes = 60 (hourly)
- interval_charge_per_gib = (10,000 / 43,200) * 60 ≈ 13.89 credits per GiB per hour

For a user with 5 GB stored:
- Hourly charge = 13.89 * 5 ≈ 69.44 ≈ 69 credits (rounded down to integer)
```

**Notes:**
- All calculations use integer arithmetic (no floating-point)
- Rounding is done **down** (floor) to avoid overcharging
- Administrator still configures using `storage_per_gib_month` (familiar unit)

## Ledger Transaction History

### Data Structure (Redis)

```
Key: "selfstack:ledger:{userID}"
Type: Redis LIST (sorted by timestamp, newest first)
Max size: 100 entries (TRIM when > 100)

Entry (JSON):
{
  "id": "txn-uuid",                    // Unique transaction ID
  "timestamp": "2025-12-19T14:30:00Z", // RFC3339
  "type": "charge|credit|debit",       // Transaction type
  "reason": "storage|ingress|egress|payment|manual", // Why
  "amount": 12000,                     // Raw credit amount (positive = credit, negative = debit)
  "balance_after": 50000,              // Balance after this transaction
  "description": "Storage for 5.2 GiB", // Human-readable
  "metadata": {                        // Extra context
    "gib_stored": 5.2,
    "interval_minutes": 60
  }
}
```

### Transaction Types

| Type | Reason | Who Initiates | Example |
|------|--------|---------------|---------|
| `credit` | `payment` | Web Monetization poller | +12300 (paid via wallet) |
| `debit` | `ingress` | Upload handler | -15000 (upload 1 GiB) |
| `debit` | `egress` | Download handler | -30000 (download 1 GiB) |
| `debit` | `storage` | Periodic charging job | -69 (1 hour storage @ 5 GiB) |
| `debit` | `manual` | Admin CLI | -5000 (admin adjustment) |
| `credit` | `manual` | Admin CLI | +1000000 (admin top-up) |

## Implementation Details

### 1. Config Loading (`config.go`)

```go
type CreditsConfig struct {
    // ... existing fields ...
    StoragePerGiBMonth      int64 `yaml:"storage_per_gib_month"`
    ChargeFrequencyMinutes  int64 `yaml:"charge_frequency_minutes"`  // NEW
}

// CalculateIntervalStorageChargePerGiB computes the per-GiB cost for the charging interval
func (c *CreditsConfig) CalculateIntervalStorageChargePerGiB() int64 {
    monthMinutes := int64(30 * 24 * 60) // 43,200
    if c.ChargeFrequencyMinutes == 0 {
        c.ChargeFrequencyMinutes = 60 // default: hourly
    }
    return (c.StoragePerGiBMonth / monthMinutes) * c.ChargeFrequencyMinutes
}
```

**Validation:**
- `ChargeFrequencyMinutes` must be > 0 (fail startup if invalid)
- Must divide evenly into month (ideally 60, 120, 240, 360, 1440, etc.)
- Recommendation: 60 (hourly) for testing, 1440 (daily) for production

### 3. Periodic Charging Job

Create `server/internal/activity/storage_charger.go`:

```go
package activity

import (
    "context"
    "log"
    "time"
    "github.com/bosbaber/hackweek/selfstack/internal/ledger"
    "github.com/bosbaber/hackweek/selfstack/internal/storage"
)

type StorageCharger struct {
    ledger              ledger.Ledger
    s3Client            *storage.S3Client
    interval            time.Duration
    chargePerGiBInterval int64 // Calculated from config
    stopCh              chan struct{}
}

func NewStorageCharger(ledger ledger.Ledger, s3Client *storage.S3Client, 
    chargeFrequencyMinutes int64, chargePerGiBInterval int64) *StorageCharger {
    return &StorageCharger{
        ledger:               ledger,
        s3Client:             s3Client,
        interval:             time.Duration(chargeFrequencyMinutes) * time.Minute,
        chargePerGiBInterval: chargePerGiBInterval,
        stopCh:               make(chan struct{}),
    }
}

func (sc *StorageCharger) Start() {
    ticker := time.NewTicker(sc.interval)
    go func() {
        defer ticker.Stop()
        for {
            select {
            case <-sc.stopCh:
                return
            case <-ticker.C:
                sc.chargeAllUsers()
            }
        }
    }()
}

func (sc *StorageCharger) Stop() {
    close(sc.stopCh)
}

func (sc *StorageCharger) chargeAllUsers() {
    // 1. List all users with stored files
    // 2. For each user:
    //    a. Calculate total stored data
    //    b. Calculate interval charge: (bytes * chargePerGiBInterval) / GiBBytes
    //    c. Debit user's account
    //    d. Record transaction
    //    e. Log charge
}
```

### 4. Redis Transaction Storage

Update ledger implementations (`ledger/redis/redis.go`, `ledger/memory/memory.go`):

```go
const transactionHistoryKey = "selfstack:transactions:{userID}"
const maxTransactionHistory = 100

func (l *Ledger) RecordTransaction(userID string, txn *Transaction) error {
    data, _ := json.Marshal(txn)
    // LPUSH to add to front (newest first)
    if err := l.client.LPush(context.Background(), 
        fmt.Sprintf(transactionHistoryKey, userID), string(data)).Err(); err != nil {
        return err
    }
    // LTRIM to keep only last 100
    return l.client.LTrim(context.Background(),
        fmt.Sprintf(transactionHistoryKey, userID), 0, maxTransactionHistory-1).Err()
}

func (l *Ledger) GetTransactionHistory(userID string, limit int) ([]Transaction, error) {
    if limit <= 0 || limit > 100 {
        limit = 50 // default
    }
    results, err := l.client.LRange(context.Background(),
        fmt.Sprintf(transactionHistoryKey, userID), 0, int64(limit-1)).Result()
    if err != nil {
        return nil, err
    }
    
    txns := make([]Transaction, 0, len(results))
    for _, result := range results {
        var txn Transaction
        if err := json.Unmarshal([]byte(result), &txn); err == nil {
            txns = append(txns, txn)
        }
    }
    return txns, nil
}
```

### 5. API Endpoint

Create `server/internal/account/transactions.go`:

```go
package account

import (
    "net/http"
    "strconv"
    "github.com/labstack/echo/v4"
    "github.com/bosbaber/hackweek/selfstack/internal/ledger"
)

func HandleGetTransactions(ledger ledger.Ledger) echo.HandlerFunc {
    return func(c echo.Context) error {
        userID := c.Get("userID").(string)
        if userID == "" {
            return c.JSON(http.StatusUnauthorized, map[string]string{"error": "missing user ID"})
        }
        
        limit := 50
        if l := c.QueryParam("limit"); l != "" {
            if parsed, err := strconv.Atoi(l); err == nil && parsed > 0 && parsed <= 100 {
                limit = parsed
            }
        }
        
        txns, err := ledger.GetTransactionHistory(userID, limit)
        if err != nil {
            return c.JSON(http.StatusInternalServerError, map[string]string{"error": "failed to fetch history"})
        }
        
        return c.JSON(http.StatusOK, echo.Map{
            "transactions": txns,
            "count": len(txns),
        })
    }
}
```

Register in `server/main.go`:
```go
e.GET("/transactions", a.withUser(account.HandleGetTransactions(ledger)))
```

## Frontend Integration

// src/app/dashboard/transactions.tsx
export function TransactionHistory() {
  const [transactions, setTransactions] = useState([])
  
  useEffect(() => {
    fetch('/transactions?limit=50')
      .then(r => r.json())
      .then(data => setTransactions(data.transactions))
  }, [])
  
  return (
    <div className="transactions">
      <h2>Transaction History</h2>
      <table>
        <thead>
          <tr>
            <th>Date & Time</th>
            <th>Type</th>
            <th>Reason</th>
            <th>Amount</th>
            <th>Balance After</th>
            <th>Description</th>
          </tr>
        </thead>
        <tbody>
          {transactions.map(txn => (
            <tr key={txn.id}>
              <td>{new Date(txn.timestamp).toLocaleString()}</td>
              <td className={`type-${txn.type}`}>{txn.type}</td>
              <td>{txn.reason}</td>
              <td className={txn.amount >= 0 ? 'positive' : 'negative'}>
                {(txn.amount / 10000).toFixed(4)} credits
              </td>
              <td>{(txn.balance_after / 10000).toFixed(4)} credits</td>
              <td>{txn.description}</td>
            </tr>
          ))}
        </tbody>
      </table>
    </div>
  )
}
